# Golden files

Generated by `python3 -m carddemo_harness golden` (see [test-harness](../test-harness/README.md)). Do not edit by hand:
`tests/test_golden.py::test_committed_golden_files_are_up_to_date` fails if these drift from the sources.

| Path | Contents |
|---|---|
| `<dataset>.json` | One per file in `app/data/ASCII/`: source SHA-256, copybook, VSAM name, key, field layout, control totals, records sorted by key |
| `export.json` | The EBCDIC CBEXPORT file decoded with CVEXPORT.cpy (COMP-3 and COMP fields): per-type layouts, counts and sums by type, the known snapshot differences, all 500 records in file order. Low-values are kept as `\u0000` |
| `manifest.json` | Record counts, control totals and source hashes for every dataset |
| `schemas/<dataset>.schema.json` | JSON Schema (draft 2020-12) derived from the copybook, with `x-cobol-pic`, `x-cobol-offset`, `x-cobol-88` |
| `schemas/export.<type>.schema.json` | One schema per export record type (C, A, X, T, D): header plus that REDEFINES body |
| `jobs/POSTTRAN.expected.json` | CBTRN02C expected output on the sample data: TRANSACT writes, DALYREJS rejects, ACCTDATA and TCATBALF after |
| `jobs/INTCALC.expected.json` | CBACT04C expected output run on the POSTTRAN result with PARM-DATE `2022-07-21`: interest transactions and ACCTDATA after |
| `jobs/reconciliation-baseline.json` | Every reconciliation check evaluated against the golden data (all pass) |

Numeric fields with decimals are strings (`"194.00"`), whole numbers are integers, and alphanumerics are right-trimmed.
